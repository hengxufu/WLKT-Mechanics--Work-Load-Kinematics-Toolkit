# 拉压弯扭大师 2.0.0 第一阶段报告

## 本轮目标

本轮将主编辑器改造为统一的二维/三维结构工作区，并为本地 GPU 计算建立可验证、可回退的后端接口。现有二维建模、材料力学教学助手和离线桌面能力保持不变。

## 完成内容

### 1. 分离分析维度和视图模式

- `AnalysisDimension`：`2d` 或 `3d`，决定当前模型和求解器。
- `ViewportMode`：`2d`、`3d` 或 `split`，只决定显示方式。
- 视图切换不触发求解，二维投影和三维场景共享节点/构件选择状态。
- 分析维度切换会使旧结果失效，避免把不同模型或维度的结果混用。

### 2. 可控的模型转换

- 二维转三维会创建独立副本，原二维模型仍保存在本机。
- 可选择空间桁架或空间刚架。
- 可选择约束新增出平面自由度，或保留为空间自由度。
- 遇到构件荷载、指定位移或桁架不支持的节点力矩时，转换会被阻止并说明原因。
- 三维转二维发现非零 Z 坐标、空间荷载、空间约束、实体单元或局部轴时，不会静默投影覆盖；用户可返回此前保留的二维模型。

### 3. 本地计算后端

新增 `ComputeBackend` 接口和统一调度器：

- `WorkerCpuComputeBackend`：默认在本地 Web Worker 中调用现有空间杆系求解器。
- `JavaScriptCpuComputeBackend`：Worker 初始化失败时的本地主线程回退。
- `WebGPUComputeBackend`：当前只完成能力检测和接口占位。
- 每次结果记录请求设备、实际设备、回退原因、耗时和残差。
- 用户取消计算时终止 Worker，不向远程服务器发送模型。

### 4. WebGPU 能力检测

检测流程实际调用：

1. `navigator.gpu`
2. `requestAdapter`
3. `requestDevice`

检测成功只表示浏览器和显卡具备 WebGPU 设备，不表示 GPU 数值内核已经实现。当前选择“本地 GPU”或“自动选择”后，系统会明确说明原因并使用 Worker CPU 求解。

### 5. 空间刚架交互补齐

空间刚架界面现可输入：

- 材料：`E`、`G`、屈服强度。
- 截面：`A`、`Iy`、`Iz`、`J`。
- 约束：`Ux/Uy/Uz/Rx/Ry/Rz`。
- 荷载：`Fx/Fy/Fz/Mx/My/Mz`。

求解仍使用现有 12×12 Euler-Bernoulli 空间梁单元和 mathjs sparse LU。

## 技术审计结论

- 二维编辑器：Vue + SVG + `ts-fem`，当前仍在主线程执行旧二维求解。
- 三维显示：Three.js，支持二维模型的三维显示和空间模型显示。
- 空间桁架/刚架：本地 TypeScript 数值内核。
- 稀疏求解：mathjs sparse LU。
- 实体 Tet4：存在实验内核，尚未纳入统一编辑工作流。
- WASM Cholesky/LDLT：尚未接入。
- WebGPU Compute：本轮前不存在；本轮只加入真实能力检测，不含数值内核。

## 当前限制

- Worker 化覆盖统一空间桁架/刚架求解；旧二维 `ts-fem` 求解尚未 Worker 化。
- WebGPU 数值计算尚未启用。
- 大模型进度目前按求解阶段报告，不是逐单元百分比。
- 取消操作通过终止 Worker 立即生效，当前同步数值内核本身没有中断点。
- 三维转二维只允许返回保留的二维模型，不自动生成可能丢失信息的投影副本。

## 下一阶段 WebGPU 数值内核路线

1. 固定 CSR 数据布局和自由度编号格式，增加 CPU/GPU 共用的二进制模型缓冲区。
2. 使用 WGSL 实现批量空间桁架单元刚度计算和载荷向量组装。
3. 实现约束消元、CSR 索引构建和重复项归并。
4. 首先接入预条件共轭梯度法，针对对称正定模型提供 GPU 求解。
5. 对非正定或病态模型保持 CPU sparse LU 回退。
6. 使用双精度 CPU 结果校核 GPU 单精度/混合精度结果，比较位移、反力、内力和相对残差。
7. 建立小、中、大模型基准，只有在准确性和性能均达标后才把 GPU 标记为实际后端。

## 验收标准

- 新增 TypeScript 核心通过独立严格类型检查。
- 空间桁架和空间刚架数值回归测试通过。
- 生产构建通过并生成独立 Worker 资源。
- 桌面和移动视口下二维、三维、分屏模式无空白和明显遮挡。
- 设备面板显示实际后端和回退原因，不将能力检测冒充 GPU 求解。
