拉压弯扭大师本地使用手册

本版本面向本地离线使用：界面资源、更新日志、说明页和计算逻辑都由本机加载，不依赖云端服务器。

第一次使用

  1. 在启动页选择 2D 或 3D 默认案例；以后可通过“帮助 → 使用指导与默认案例”重新打开。
  2. 从左侧模型树检查几何、材料、截面、约束和荷载，在中间视口确认方向，在右侧面板调整参数。
  3. 点击“求解”或“本地求解”。软件会先校核模型，再在用户本机完成计算。
  4. 通过结果类型、教学助手和结果表检查反力、内力、变形、推导过程与危险位置。

默认学习案例

  • 2D 简支梁弯曲：6 m 简支梁承受跨中 18 kN 集中力，载入后自动求解，适合学习支反力、剪力图、弯矩图、挠度与危险截面。
  • 3D 空间悬臂刚架：三段正交 Q235 空间刚架在自由端承受三向力和扭矩，适合学习六自由度、局部坐标、双向弯曲、扭转与组合响应。

安装为本地 App

  1. 在项目根目录执行 npm install 安装依赖。
  2. 执行 npm run app:build 生成离线构建。
  3. 执行 npm run app:preview，浏览器打开 http://127.0.0.1:4173。
  4. 在 Edge 或 Chrome 地址栏右侧选择“安装应用”，安装后即可从开始菜单或桌面启动。
首次安装需要本机预览服务提供安装入口。安装并打开过一次后，应用资源会被 service worker 缓存，可在离线状态下继续使用。

离线使用注意

  • 模型文件通过“保存项目”和“打开项目”在本地 JSON 文件中交换。
  • 分享链接只编码当前模型，不上传模型数据；在完全离线环境下建议优先使用项目 JSON 文件。
  • 本版本已移除 Google Analytics、Sentry、远程字体加载和周期性自动更新检查。
  • 荷载、弯矩、刚度、强度等输入支持 F、M、E、I、L、k、sigma、fy 等本地符号表达式。

分享给其他人

  • 推荐通过 GitHub Pages 分享静态网页版本；访问者的计算和项目文件都保留在访问者自己的浏览器与电脑中。
  • 也可以通过 GitHub Release 分享离线压缩包；对方下载后运行 node serve-local.mjs app 4173，再打开 http://127.0.0.1:4173/。
  • 不要分享你电脑上的 localhost、127.0.0.1 或局域网 IP 地址，也不要配置端口转发或内网穿透到你的电脑。

教学功能入口

  • “教学助手 → 分步推导”显示平衡方程、边界条件、内力方程和符号约定。
  • “教学助手 → 典型题库”提供悬臂梁、简支梁、外伸梁、刚架、桁架、组合杆和温度荷载案例。
  • “教学助手 → 危险截面”识别最大正应力、最大剪应力、最大挠度和安全系数。
  • 提供单位一致性检查和量纲提示，减少 MPa、N、kN、mm、m 混用导致的输入错误。
  • 三维工作区提供空间桁架、空间刚架和实验性 Tet4 实体有限元计算。
