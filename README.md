# 拉压弯扭大师

![拉压弯扭大师图标](public/app-icon.png)

**2.0.0 · 面向材料力学学习的本地离线求解与公式计算软件**

拉压弯扭大师是一款面向材料力学、结构力学基础和杆系分析学习场景的桌面软件。软件围绕"拉伸压缩、弯曲、扭转、组合变形"四类核心问题组织功能，帮助使用者完成建模、求解、推导、危险截面识别和字母公式计算。

本项目直接面向材料力学学习、教学演示和应试训练开发，不是北京航空航天大学官方软件，不得用于实际工程设计、工程鉴定或商业用途。

架构关键约束：
- 求解核心纯 TypeScript，不读取 Pinia/Vue，函数式输入输出
- 适配器集中在 `structuralAdapters.ts`，不在 Vue 组件中做求解转换
- 三维结果绑定 `modelRevision`，模型修改后旧结果立即标记过期
- 设备面板显示**实际后端**和回退原因，WebGPU 能力检测不冒充 GPU 求解

## 求解器能力矩阵

| 求解器 | 节点自由度 | 单元刚度 | 载荷类型 | 输出结果 | 接入主编辑器 |
| --- | --- | --- | --- | --- | --- |
| 平面刚架 (Beam2D) | `Dx, Dz, Ry` | 6×6 (含 Timoshenko 剪切修正) | 节点力/弯矩、均布/梯形、单元集中力/矩、温度、指定位移 | 位移、反力、N/V/M 图 | ✅ 主线程 |
| 空间桁架 (spaceTruss3D) | `Ux, Uy, Uz` | 6×6 (EA/L 方向余弦外积) | 节点三向力、指定平移 | 位移、反力、轴力、正应力、安全系数 | ✅ Worker |
| 空间刚架 (spaceFrame3D) | `Ux, Uy, Uz, Rx, Ry, Rz` | 12×12 (Euler-Bernoulli) | 节点六分量力/力矩、指定六自由度 | 六自由度位移、反力、N/Vy/Vz/T/My/Mz、估算应力/安全系数 | ✅ Worker |
| 实体 Tet4 (solidTetra3D) | `Ux, Uy, Uz` | 12×12 (常应变四面体) | 节点三向力、指定平移 | 位移、反力、常应变、六应力、von Mises、安全系数 | ⚠️ 实验性 |

矩阵后端一致性：`dense`、`sparse-assembly`、`sparse-lu` 三者结果等价，由等价性测试保证。

## 核心功能

- **多语言界面**：简体中文 / 英语 / 捷克语 / 德语 / 西班牙语 / 法语 / 波兰语 / 葡萄牙语 / 俄语 / 泰语 / 乌克兰语（共 11 种），默认简体中文。
- **本地离线运行**：桌面版安装后不依赖云端服务器，结构求解、符号表达式和项目文件处理都在用户自己的电脑完成。
- **二维杆系建模**：支持节点、梁单元、材料、截面、支座约束、节点荷载、单元荷载、集中力矩、梯形荷载和温度荷载。
- **统一二维/三维工作区**：分析维度 (`2d/3d`) 与视图模式 (`2d/3d/split`) 相互独立；切换视图不重复求解，共享节点/构件选择状态。
- **可控模型转换**：二维转三维创建独立副本（可选桁架/刚架、可选出平面约束处理），转换失败时阻止并说明原因；三维转二维只允许返回保留副本，不静默投影覆盖。
- **三维线单元求解闭环**：空间桁架和空间刚架均已实现"建模 → 校核 → 本地 Worker 求解 → 结果表 → 三维变形与内力显示"。
- **本地 Worker 求解**：空间杆系求解在浏览器 Web Worker 中执行，界面保持响应；取消计算终止 Worker；Worker 不可用时回退主线程 CPU 并提示原因。
- **计算设备透明**：支持自动、本地 GPU（实验检测）、本地 CPU 三档；2.0.0 仅真实检测 WebGPU 能力，数值内核仍使用 CPU，设备面板明确说明实际后端。
- **结果查看**：支反力、轴力、剪力、弯矩、变形图、单元端力，以及三维位移、轴力着色和危险截面汇总。
- **字母计算**：支持 `F`、`N`、`V`、`M`、`T`、`E`、`G`、`A`、`I`、`J`、`W`、`Wt`、`L`、`fy` 等常用材料力学字母参与计算。
- **常用公式库**：内置轴向应力、弯曲应力、扭转剪应力、von Mises、轴向变形、悬臂梁挠度、简支梁挠度、扭转角、EA、EI、温度应力和安全系数公式。
- **组合变形**：拉伸/压缩、弯曲、扭转三类作用组合下的应力、变形和安全系数计算。
- **教学助手**：分步推导、典型题库模板、危险截面识别和三维有限元教学示例。
- **自由点尺寸标注**：标注起止点无需创建 FE 节点，支持端点拖拽、捕捉、反向和坐标直接编辑。
- **线性变化荷载**：三角形、梯形分布荷载，预览与结果均支持；同向分布荷载和节点荷载自动堆叠提升可视性。
- **撤销/重做重构**：统一操作历史，复制/粘贴/删除等操作均可靠回退。
- **本地安装包**：支持生成 Windows 一键安装 `.exe`，也支持 PWA、GitHub Pages 和离线静态包分发。

## 生成 Windows 安装包

推荐使用项目内置 Node 工具链：

```powershell
$env:Path = "$PWD\.local-tools\node-v22.22.2-win-x64;$env:Path"
.\.local-tools\node-v22.22.2-win-x64\npm.cmd run desktop:dist:win
.\.local-tools\node-v22.22.2-win-x64\npm.cmd run release:checksums
```

生成文件：

```text
release/desktop/拉压弯扭大师-<version>-x64-Setup.exe
release/desktop/SHA256SUMS.txt
release/desktop/release-manifest.json
```

校验安装包：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\verify-installer.ps1 .\release\desktop
Get-FileHash .\release\desktop\拉压弯扭大师-<version>-x64-Setup.exe -Algorithm SHA256
Get-AuthenticodeSignature .\release\desktop\拉压弯扭大师-<version>-x64-Setup.exe
```

没有正式代码签名证书时，安装包可以安装使用，但 Windows 不能证明发布者身份。公开分发前建议配置代码签名证书；没有证书时至少提供 SHA256 哈希，便于识别文件是否被篡改。

## 2.0.0 三维有限元进展

当前三维有限元核心已扩展到三类本地求解模块：

- `spaceTruss3D`：三维桁架单元，支持 3 个平动自由度、轴力、应力和安全系数。
- `spaceFrame3D`：三维梁/刚架单元，支持 6 个节点自由度、轴向、双向弯曲、扭转和端部内力。
- `solidTetra3D`：四节点三维实体四面体单元，支持实体位移、常应变、三维应力、von Mises 应力、最大危险单元和最小安全系数识别。

三维模块均在用户本地运行，可选择 `dense`、`sparse-assembly` 或 `sparse-lu` 矩阵后端，不依赖云端服务器。

统一结构工作区当前已开放空间桁架与空间刚架工作流：

1. 定义材料 `E/G`、屈服强度和截面 `A/Iy/Iz/J`。
2. 输入节点真实 `X/Y/Z` 坐标和 `Ux/Uy/Uz/Rx/Ry/Rz` 约束。
3. 连接空间杆件并施加 `Fx/Fy/Fz/Mx/My/Mz` 节点荷载。
4. 通过模型检查后在本地 Worker 中执行 sparse LU 求解。
5. 查看节点位移、支座反力、杆件轴力/剪力/弯矩/扭矩、正应力、安全系数和三维变形。

求解结果绑定模型修订号。几何、材料、截面、约束或载荷改变后，旧结果会标记为过期，不再作为当前模型结果显示。

当前限制：

- 空间桁架只承受轴力，不支持节点力矩、构件分布荷载和弯矩/剪力结果。
- 空间刚架采用 12×12 Euler-Bernoulli 单元，可输入节点力矩并查看轴力、双向剪力、双向弯矩和扭矩结果；无构件荷载/温度/初始应变。
- Tet4 仅为实验性常应变实体内核，尚无网格导入、应力恢复和连续实体云图。
- `sparse-lu` 当前基于 mathjs，不是 WASM Cholesky/LDLT。
- WebGPU 当前只完成本机能力检测（navigator.gpu → requestAdapter → requestDevice），GPU 刚度组装、约束处理和迭代求解内核尚待下一阶段实现。

本轮实现、限制与下一阶段路线见 [2.0.0 第一阶段报告](docs/version-2.0-stage-1.md) 与 [求解器能力审计](docs/solver-capability-audit.md)。
