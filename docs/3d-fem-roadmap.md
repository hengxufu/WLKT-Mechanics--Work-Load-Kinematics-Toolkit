# 三维有限元求解技术路线

本文档用于约束拉压弯扭大师从二维杆系扩展到三维有限元求解的开发范围、阶段目标和验收标准。当前目标是先实现可教学、可验证、可离线运行的三维线单元有限元，而不是直接进入板壳和实体网格。

## 范围定义

第一阶段支持空间桁架单元：

- 每个节点 3 个平动自由度：`Ux`、`Uy`、`Uz`
- 单元只承受轴力，局部刚度为 `EA/L`
- 支持任意空间方向、节点荷载、位移约束、符号参数
- 输出节点位移、支座反力、单元轴力、正应力和安全系数

第二阶段支持空间梁/刚架单元：

- 每个节点 6 个自由度：`Ux`、`Uy`、`Uz`、`Rx`、`Ry`、`Rz`
- 支持轴向、双向弯曲、扭转和组合变形
- 输出 `N`、`Vy`、`Vz`、`T`、`My`、`Mz`
- 与现有组合变形校核、危险截面识别和分步推导面板打通

板壳单元和实体单元放到后续版本。它们需要网格划分、面/体单元、等参映射、积分点应力恢复和更完整的后处理，不应和空间杆系核心混在同一个里程碑中完成。

## 当前落地

已新增空间桁架核心：

- `src/utils/spaceTruss3D.ts`
- `src/tests/spaceTruss3D.test.ts`

该模块是纯本地计算模块，不连接云端服务器。输入模型数据后直接在本机完成刚度矩阵组装、边界条件处理、线性方程求解和结果恢复。

已新增空间梁/刚架核心：

- `src/utils/spaceFrame3D.ts`
- `src/tests/spaceFrame3D.test.ts`

该模块实现 12 自由度 Euler-Bernoulli 空间梁/刚架单元。当前支持轴向、双向弯曲、扭转、节点力/力矩、位移/转角约束、局部坐标系转换、杆端局部内力、最大正应力和安全系数。分布荷载、端部释放、Timoshenko 剪切变形和三维 UI 接入放在后续子任务。

已新增三维后处理核心：

- `src/utils/spacePostprocess3D.ts`
- `src/tests/spacePostprocess3D.test.ts`

该模块把空间桁架和空间梁/刚架结果统一整理为危险位置清单，当前支持最大位移、最大轴力、最大剪力、最大扭矩、最大弯矩、最大正应力、最大剪应力和最小安全系数。

## 数据模型

建议三维模型采用独立 schema，并保留二维模型兼容迁移：

```ts
type SpaceTrussModelInput = {
  nodes: SpaceTrussNodeInput[];
  elements: SpaceTrussElementInput[];
  materials?: SpaceTrussMaterialInput[];
  sections?: SpaceTrussSectionInput[];
  nodalLoads?: SpaceTrussLoadInput[];
  symbols?: Record<string, number>;
};
```

后续保存文件建议增加：

- `schemaVersion`
- `analysisDimension: "2d" | "3d"`
- `elementType: "beam2d" | "truss3d" | "frame3d"`
- `localAxisRef`，用于空间梁/刚架局部坐标系定义

旧二维模型可映射为 `y = 0` 的三维坐标，但二维梁单元不应被自动当作空间梁单元，避免结果含义变化。

## 求解阶段

### M1 空间桁架

目标：完成三维桁架的端到端求解核心。

验收：

- 单杆轴向位移满足 `u = PL/EA`
- 任意空间方向杆的单元刚度矩阵对称
- 支座反力满足整体平衡
- 支持 `F`、`E`、`A`、`L` 等符号表达式
- 对零长度、缺失节点、非正截面面积、非正弹性模量给出明确错误

### M2 空间梁/刚架

目标：实现 12x12 空间梁单元。

核心内容：

- 每节点 6 自由度
- 局部坐标系由杆轴方向和用户参考向量确定
- 刚度包含 `EA`、`GJ`、`EIy`、`EIz`
- 支持端部铰接和自由度释放
- 输出局部杆端力：`N`、`Vy`、`Vz`、`T`、`My`、`Mz`

当前状态：

- 已完成 12x12 局部刚度矩阵
- 已完成局部/全局坐标转换
- 已完成节点力和节点力矩求解
- 已完成节点 6 自由度约束
- 已完成局部杆端力输出
- 已完成轴向、弯曲、扭转解析测试
- 端部释放、分布荷载和三维 UI 尚未接入

验收：

- 悬臂梁端力作用下满足 `PL^3/(3EI)`
- 扭转载荷满足 `theta = TL/GJ`
- 纯轴向、纯弯曲、纯扭转和组合工况均通过解析解
- 整体模型刚度矩阵对称
- 旋转整个模型后单元局部内力保持一致

### M3 三维后处理

目标：把三维结果转化为材料力学教学结果。

内容：

- 变形形状
- 轴力图
- 双向剪力图
- 双向弯矩图
- 扭矩图
- 最大正应力、最大剪应力、最大挠度、安全系数
- 组合应力：`sigma = N/A ± My/Wy ± Mz/Wz`

当前状态：

- 已完成空间桁架后处理汇总
- 已完成空间梁/刚架后处理汇总
- 已完成最大位移、内力、应力和安全系数危险位置识别
- 已完成端部危险截面识别，适用于当前节点荷载工况
- 分布荷载下的跨中极值采样、三维图形叠加和 UI 面板尚未接入

### M4 三维交互

目标：建立三维建模和查看界面。

建议：

- 使用 Three.js 渲染三维杆系
- 使用 OrbitControls 做旋转、缩放、平移
- 节点、杆件、荷载、约束使用射线拾取
- 常用视图：前视、俯视、侧视、等轴测
- 支持网格捕捉、坐标输入和批量属性赋值

当前状态：

- 已在教学助手中接入“三维有限元”视图
- 已能调用本地空间刚架求解器和三维后处理核心
- 已能展示最大位移、最大内力、最大应力和最小安全系数
- 当前视图使用教学示例空间悬臂刚架，不自动转换二维模型
- 三维 Three.js 画布、空间节点/单元编辑、三维荷载和约束交互仍待开发

### M5 稀疏矩阵与性能

目标：让中大型模型可用。

建议：

- 小模型保留 dense solver 作为参考实现
- 大模型切换 sparse matrix backend，并优先使用 sparse LU 求解
- 求解放入 Web Worker，避免界面卡死
- 后续可接入 WASM Cholesky/LDLT 求解器作为对称正定系统的性能增强

当前状态：

- 已新增 `src/utils/femLinearAlgebra.ts`
- 已抽象全局矩阵后端：`dense`、`sparse-assembly` 与 `sparse-lu`
- 已将空间桁架和空间梁/刚架求解器接入统一矩阵后端
- 已保留 dense 求解作为默认参考实现
- 已增加后端等价性测试，确保 dense、sparse-assembly 与 sparse-lu 结果一致
- 已接入 `mathjs` `SparseMatrix` + `lusolve(A, b, order, threshold)` 的 sparse LU 路径
- `sparse-lu` 后端在自由自由子矩阵上直接构造 SparseMatrix，并使用 sparse LU 求解位移
- `sparse-assembly` 保留为兼容后端，负责稀疏装配和矩阵向量乘法
- 真正面向更大规模模型的 WASM Cholesky/LDLT 求解器、Web Worker 调度和分块装配仍可继续增强

## 测试基准

必须长期保留以下测试：

- 单根轴向杆：`PL/EA`
- 任意方向空间杆：刚度矩阵对称、反力平衡
- 空间悬臂梁：端力、端弯矩、端扭矩解析解
- 简单空间刚架：与可信有限元软件交叉校验
- 组合变形：`N + My + Mz + T`
- 机制模型：缺少约束时应报错或给出明确诊断
